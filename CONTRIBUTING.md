# Contributing

When contributing emojis to this project, please follow these guidelines:

1. **Only edit the `Emojis` folder**

   * Add or update emoji images inside the `Emojis` folder.
   * If needed, update `Alias.json`.

2. **Re-encode any images you add**

   * All uploaded images must be re-encoded before being added to the project.
   * This helps remove unwanted metadata, IP loggers, or anything else embedded in the file.

3. **Keep image sizes reasonable**

   * Emojis should not be excessively large.
   * Some existing emojis may be bigger than ideal, but please avoid anything extreme, such as 2K-resolution images.
   * Oversized emojis can cause lag, especially on lower-end devices.

4. **Prefer transparent images**

   * Please try to use transparent images when possible.
   * This is mostly a personal preference, and I understand that transparency will not make sense for every emoji.
